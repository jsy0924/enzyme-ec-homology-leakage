# 상동성 누출이 효소 기능 예측 성능 평가에 미치는 영향

단백질 서열로 효소의 EC 클래스(7종)를 예측하는 네 가지 방법을, 훈련셋과 테스트셋 사이의
서열 유사성을 단계적으로 차단하면서 비교한 기록입니다.

**핵심 결과: 무작위 데이터 분할은 성능을 macro-F1 기준 약 0.09 부풀리며, 그 부풀림의 크기는
ESM-2 8M, ESM-2 650M, BLAST에서 통계적으로 구별되지 않았습니다.** 모델을 약 80배 키우면
성능은 올라가지만 상동성 의존성은 줄지 않았습니다.

\---

## 1\. 비교한 방법

|기호|방법|입력|분류기|
|-|-|-|-|
|A|아미노산 조성 기준선|20차원 빈도 벡터|다항 로지스틱 회귀|
|B|ESM-2 8M|320차원 임베딩 (가중치 고정)|다항 로지스틱 회귀 (동일)|
|C|ESM-2 650M|1,280차원 임베딩 (가중치 고정)|다항 로지스틱 회귀 (동일)|
|D|BLAST 최근접 이웃|서열 자체|가장 닮은 훈련 서열의 EC 복사|
|D+C|하이브리드|—|BLAST가 답하면 D, 답이 없으면 C|

세 모델(A·B·C)은 표현만 다르고 분류기는 완전히 같습니다. 언어모델은 미세조정하지 않았습니다.

## 2\. 데이터 분할

* **무작위 분할**: 서열을 낱개로 섞어 5-fold
* **클러스터 분할 4단계**: 4-mer Jaccard 유사도가 기준치 T 이상인 서열 쌍을 간선으로 이은
그래프의 연결 요소를 한 가족으로 묶고, 가족 전체를 같은 fold에 배정 (T = 0.30 / 0.20 / 0.10 / 0.05)

분할을 만든 뒤 훈련–테스트 간 최대 유사도를 전부 다시 계산해 누출 차단을 검증했습니다.

|분할|클러스터 수|단독 서열|훈련–테스트 최대 J (실측)|
|-|-|-|-|
|무작위|–|–|**0.987**|
|T = 0.30|5,503|4,762|0.299|
|T = 0.20|5,098|4,235|0.199|
|T = 0.10|4,337|3,320|0.100|
|T = 0.05|3,580|2,515|0.050|

## 3\. 결과

macro-F1 (seed 42):

|방법|무작위|T=0.30|T=0.20|T=0.10|T=0.05|하락폭 \[95% CI]|
|-|-|-|-|-|-|-|
|A. 조성|0.396|0.391|0.387|0.379|0.372|0.024 \[0.014, 0.035]|
|B. ESM-2 8M|0.804|0.768|0.759|0.743|0.711|0.093 \[0.077, 0.112]|
|C. ESM-2 650M|0.936|0.915|0.899|0.881|0.848|0.088 \[0.071, 0.107]|
|D. BLAST|0.926|0.915|0.907|0.884|0.827|0.099 \[0.073, 0.125]|
|D+C. 하이브리드|0.948|0.939|0.930|0.916|**0.880**|0.068 \[0.053, 0.087]|

* 하락폭 차이: B−C = 0.006 (p = 0.52), D−C = 0.011 (p = 0.59), D−B = 0.006 (p = 0.88) → 모두 유의하지 않음
* 조성 기준선만 하락폭이 작음: B−A = 0.070 (p < 0.001)
* 라벨을 섞은 대조군의 macro-F1 = 0.142 (우연 수준 1/7 ≈ 0.143)
* 가장 엄격한 분할에서 BLAST는 서열의 21.5%(1,507개)에 답하지 못함. 그중 650M이 65.3%를 맞힘
(CTP 합성효소 가족 제외 시 60.5%)

## 4\. 폴더 구성

```
01\_main/      본 실험. run\_main.py 가 데이터 수집 → 임베딩 → 분할 → 학습 → 평가를 모두 수행
02\_stats/     부트스트랩 신뢰구간, 시드 10종 반복, 혼동 행렬
03\_blast/     DIAMOND 정렬, BLAST 최근접 이웃 예측, 하이브리드
04\_biology/   생물학 사례 분석용 후보 목록 (예측 불일치 사례, 고동일성·다른 클래스 쌍)
05\_tsne/      부록: 임베딩 t-SNE와 15-NN 이웃 순도 (논문 본문에서는 제외)
figures/      논문에 사용한 그림 7개와 생성 스크립트
data/         sequences\_main.csv (7,000개 서열, 라벨, 메타데이터)
```

## 5\. 재현 방법

### 5.1. 본 실험 (Windows, CPU)

```bat
01\_main\\1\_setup.bat          :: 파이썬 패키지 설치
01\_main\\2\_install\_torch.bat  :: PyTorch (CPU 버전)
01\_main\\3\_run\_main.bat       :: 데이터 수집 + 모델 A, B
01\_main\\4\_run\_650M.bat       :: ESM-2 650M 임베딩 + 모델 C
```

`run\_main.py`는 UniProt REST API에서 직접 서열을 받습니다. `data/sequences\_main.csv`가
이미 있으면 `--refetch` 없이 그 파일을 재사용합니다.

### 5.2. 통계 검정

```bash
python 02\_stats/reproduce.py    # 예측값 재생성 (preds.npz)
python 02\_stats/bootstrap.py    # 서열 가족 단위 부트스트랩 2,000회
python 02\_stats/seeds.py        # fold 배정 시드 10종 반복
python 02\_stats/summarize.py    # stats\_table.csv 출력
```

### 5.3. BLAST

```bat
03\_blast\\run\_blast.bat
```

DIAMOND 2.1.10을 미리 설치해야 합니다 ([https://github.com/bbuchfink/diamond/releases](https://github.com/bbuchfink/diamond/releases)).
저장소에는 실행 파일을 포함하지 않았습니다.

```
diamond blastp --very-sensitive --evalue 1e-3 --max-target-seqs 0
```

7,000개 서열을 한 번에 all-vs-all 정렬한 뒤, fold마다 훈련셋에 해당하는 결과만 사용합니다.

## 6\. 실험 환경

* Windows 11, Python 3.11, **CPU만 사용** (GPU 없음)
* ESM-2 650M 임베딩 계산: 약 17시간 (7,000개 서열)
* ESM-2 8M 임베딩: 약 20분
* DIAMOND all-vs-all 정렬: 수 분
* `02\_stats/`, `03\_blast/analysis/`, `04\_biology/`, `05\_tsne/`의 스크립트는 Linux 환경에서
실행했습니다. 각 파일 상단의 경로 상수를 자신의 환경에 맞게 바꿔야 합니다.

## 7\. 데이터 출처

UniProt Swiss-Prot, 릴리스 2026\_04 (2026-11-04 기준), CC BY 4.0.

선별 조건: 검수된 항목(reviewed), EC 번호가 하나만 주석된 효소, 길이 100\~1,000 잔기,
조각 서열 아님, 표준 아미노산 20종만 포함, 서열 중복 없음. EC 클래스별로 API 반환 순서대로
1,000개씩 취해 총 7,000개.

구성: 854종 생물 (사람 2,623개), 서로 다른 EC 번호 1,619종, 길이 중앙값 467 잔기.

## 10\. 한계

* 분할에 사용한 4-mer Jaccard 유사도는 정렬 기반 동일성의 근사입니다. 가장 엄격한 분할에서도
테스트 서열의 78.5%는 훈련셋에 정렬 가능한 상동체가 있었고(동일성 중앙값 36.8%, 최대 63.5%),
따라서 보고된 하락폭은 누출 효과의 **하한**입니다.
* ESM-2는 UniRef 서열로 사전훈련되었으므로 테스트 서열 대부분을 라벨 없이 이미 보았을 것입니다.
클러스터 분할은 분류기의 훈련셋만 분리하며, 언어모델의 사전훈련 데이터는 통제하지 못합니다.
* EC 번호의 첫째 자리(7개 클래스)만 다루었습니다.
* 하이브리드 모델은 결과를 본 뒤에 설계한 탐색적 모델입니다.
* 단일 데이터 표본이며 사람 단백질이 37%를 차지합니다.
