# 부록: t-SNE 시각화

임베딩이 EC 클래스별로 뭉치는지 눈으로 확인하려고 그린 그림입니다. 보고서에는 따로 넣지 않았습니다.

15-최근접이웃 이웃 순도(같은 클래스인 이웃의 비율)는 다음과 같았습니다.

|표현|이웃 순도|가장 엄격한 분할의 macro-F1|
|-|-|-|
|A. 조성|0.40|0.372|
|B. ESM-2 8M|0.68|0.711|
|C. ESM-2 650M|0.67|0.848|

8M과 650M의 순도가 거의 같아, 성능 차이(0.138)를 설명하지 못합니다. 2차원으로 눌러 그린
그림이 1,280차원 공간에서 선형 분류기가 쓰는 정보를 보여 주지 못하기 때문입니다. 그림이
이야기와 맞지 않으므로 본문에서 빼고, 과정 기록으로만 남겼습니다.
