# 생물학 사례 조사용 후보 목록

공유 스프레드시트 "효소 사례 조사표"에 들어간 표본의 원본과, 표본에 뽑히지 않은 사례까지 포함한 전체 목록입니다. 엑셀에서 한글이 깨지지 않도록 UTF-8(BOM)으로 저장했습니다.

| 파일 | 내용 |
|---|---|
| `idea1_all_7000_strict_split.csv` | 7,000개 전부. 가장 엄격한 분할(J < 0.05)에서 정답, 650M·8M·BLAST 예측, 범주(A~F), BLAST 최근접 훈련 서열과 동일성, 데이터셋 내 고아 여부 |
| `idea1_sample.csv` | 조사표 1번 시트에 들어간 56건 |
| `idea2_high_identity_different_class.csv` | 양쪽 80% 이상 정렬, 동일성 50% 이상인데 EC 클래스가 다른 37쌍 (전부) |
| `idea2_partial_match_different_class_all.csv` | 동일성 50% 이상인데 한쪽의 50% 미만만 정렬되고 EC 클래스가 다른 62쌍 |
| `idea2_partial_match_sample.csv` | 위 62쌍 중 조사표에 들어간 20쌍 |
| `idea2_identity_vs_EC_level.csv` | 동일성 구간별로 EC 1~4자리가 같은 쌍의 비율 |

## 범주 (idea1)

| 코드 | 의미 | 개수 |
|---|---|---|
| A | BLAST 답 없음, 650M 맞힘 | 984 |
| B | BLAST 답 없음, 650M 틀림 | 523 |
| C | BLAST 맞힘, 650M 틀림 | 342 |
| D | BLAST 틀림, 650M 맞힘 | 123 |
| E | 둘 다 답했고 둘 다 틀림 | 196 |
| F | 둘 다 맞힘 | 4,832 |

## 표본 규칙

미리 정한 규칙으로 뽑았습니다(시드 2026). idea1은 범주 A~D × EC 클래스 7개 × 2건, idea2 고동일성은 37쌍 전부, 부분 정렬은 62쌍 중 20쌍 무작위입니다. 결론이 고른 사례에 좌우되지 않도록, 표본을 바꾸거나 추가로 고르지 않습니다.
